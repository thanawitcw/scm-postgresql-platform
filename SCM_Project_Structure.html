Rules that hold everywhere: one transaction per load (DELETE+INSERT+DQ, one COMMIT) · DDL only from Alembic, never from a load · idempotent re-runs · orphans/quarantine load with WARN, never silently dropped · ~$ lock files skipped centrally · extract failures write FAILED run rows naming the datasource.

🗂 Schemas

stg — Staging

Raw, close to source, disposable. Truncate-then-load every run. Never read by dashboards. 9 tables.

core — Base layer

Typed, constrained, Alembic-owned. 5 dims (dim_date, dim_dc, dim_channel, dim_supplier, dim_item) + 7 facts. Engine-owned, never ad-hoc.

rpt — Contract

The ONLY surface consumers may read. Versioned .sql files. Business logic lives here, not in DAX.

ops — Provenance

etl_run (every load attempt), dq_result (WARN/ERROR), dataset (file hashes), promotion_change_log, 30 progrid snapshots.

👁 Views (rpt — the only consumer surface)

rpt.v_freshness
One row per loaded table: data_through, row_count, last_loaded_at, coverage_lag_days, is_stale (per-source thresholds 3d→45d). First stop for every dashboard.
rpt.v_fact_progrid_bestprice
Resolved promo price, 1 row per date × item × unit (443K rows). Lowest price wins; MAIL only on ties. A view, not a table (Rule M11).
rpt.v_promotion_changes
Change log aggregated to promotion level at query time (ADDED / PROMO CANCELLED / PRICE UP-DOWN, TYPE-THEME CHANGED, DATES EXTENDED-CUT, old/new promo window + dates_verdict).
rpt.v_promotion_effective_periods
Gaps-and-islands: when a promotion was actually the applied price.
rpt.v_unmapped_values
pro_types outside the 7 canonical values (currently 14-DAYS, 7-DAYS_*, 3-DAYS). Business-classification watchlist.

File logs in ops\logs\daily_YYYYMMDD.log (one per daily run, GREEN/RED footer). Database truth in ops.etl_run (every attempt, incl. extract failures) + ops.dq_result (WARN loads / ERROR rolls back) + ops.dataset (filename + sha256 per source).
LogWritten by

ops.dq_resultpipelines — check_name, severity, passed, observed/expected
ops.datasetCLI — dataset_key, file_name, content_hash, business min/max ( powers SKIP logic)
